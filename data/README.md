# Dataset

Unduh dataset dari [Rice Disease Dataset di Kaggle](https://www.kaggle.com/datasets/anshulm257/rice-disease-dataset) secara manual atau dengan Kaggle CLI sesuai ketentuan akun dan lisensinya.

Letakkan file asli di `data/raw/`. Folder dataset dan hasil olahan di `data/processed/` diabaikan oleh Git agar file gambar tidak ikut terunggah. Jangan commit kredensial Kaggle.

Data Engineer perlu mencatat nama kelas, jumlah gambar per kelas, versi/sumber dataset, aturan split, seed split, dan langkah preprocessing di notebook atau laporan.
